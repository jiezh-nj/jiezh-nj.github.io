# Jie Zhang — GitHub Pages homepage

This is a minimal academic homepage prepared for OpenReview / conference profile use.

## Before publishing

Open `index.html` and replace:

- `[Your University]`
- `YOUR_SCHOOL_EMAIL`

Use the same public email that you use on OpenReview if possible.

## Publish with GitHub Pages

Your GitHub username is `jiezh-nj`, so create a **public** repository named exactly:

`jiezh-nj.github.io`

Then upload `index.html` and `style.css` to the root of that repository.

GitHub Pages should publish the site at:

`https://jiezh-nj.github.io/`

If it does not appear automatically:
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Save and wait a minute or two.

Then use `https://jiezh-nj.github.io/` as the Homepage URL on OpenReview.
